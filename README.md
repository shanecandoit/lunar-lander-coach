Lunar Lander Coach

Simple Go/Ebiten implementation of a Lunar Lander-style game.

Controls
- Arrow Left/Right: rotate the lander
- Arrow Up: thrust
- P: pause/unpause

Run
1. Ensure you have Go installed (1.20+ recommended).
2. From the project directory run:

```bash
go run .
```

Notes
- The game uses `github.com/hajimehoshi/ebiten/v2` for rendering and input.
- Tweak physics constants in `main.go` for easier/harder gameplay.
